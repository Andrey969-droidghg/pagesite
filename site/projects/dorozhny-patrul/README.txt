ДОРОЖНЫЙ ПАТРУЛЬ - классный час по ПДД Республики Беларусь, 7 класс

КАК ЗАПУСТИТЬ
1. Распакуйте архив в любую папку (вместе с папкой videos).
2. Откройте файл index.html двойным щелчком (Chrome, Edge, Firefox, Safari).
Ничего устанавливать не нужно, сервер не нужен.

СТРАНИЦЫ
  index.html     главная
  learn.html     правила по пяти темам с картинками
  game.html      одиночная игра «Станции»
  class.html     командная игра для проектора (таймер, выбор темы)
  glossary.html  знаки и термины с поиском
  video.html     пять анимированных роликов, вопросы к ним, ссылка на видео БЕЛТА
  awards.html    удостоверение и значки
  teacher.html   сценарий на 45 минут

ФАЙЛЫ
  style.css      оформление (светлая, тёмная и системная тема)
  theme.js, common.js, art.js, data.js, quiz.js  общий код
  game.js, class.js, glossary.js, video.js, awards.js, teacher.js  код страниц
  videos/        ролики t1.mp4 ... t5.mp4 (по 40-45 секунд, без озвучки, с субтитрами)

ЗАМЕТКИ
- Шрифты подгружаются из Google Fonts. Без интернета всё работает, шрифты станут системными.
- Ролики играют без интернета. Озвучки нет, комментируйте их сами.
- Свой ролик положите в папку videos под тем же именем (t1.mp4 ... t5.mp4), он заменит анимацию.
- Прогресс ученика хранится в браузере на этом компьютере. Чтобы открыть все станции сразу,
  зайдите на страницу «Учителю» и нажмите «Открыть все станции».
- Вопросы можно менять в data.js (массив STATIONS). Знаки и термины лежат в glossary.js.
- Перед занятием сверьте нормы с действующей редакцией ПДД на pravo.by.
